**English** | [Português (Brasil)](NOTICE.pt-BR.md)

`ISC BIND 9 by Zabbix Agent` is an independent community project.

## Origin

The initial monitoring architecture was inspired by and partially based on:

- **bind9 by HTTP-JSON Agent 2 Active**
- Author: **Gabriele Rossetti (KaleidoscopeIT)**
- Source: Zabbix Community Templates repository
- Upstream license: **MIT**

The maintained project substantially redesigns and extends the original template, including Agent/Agent 2 neutrality, additional BIND statistics endpoints, zone discovery, security defaults, repository validation, versioning and bilingual documentation.

ISC BIND statistics endpoint semantics are implemented from public ISC BIND documentation and interoperability testing. ISC BIND itself is a separate project and is not redistributed here.
